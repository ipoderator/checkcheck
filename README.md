# ВсеЧеки — сайт производителя кассовой ленты

Одностраничный сайт на русском: лендинг + корпоративные разделы, форма-«чек» с заявками «Рассчитать цену» и «Сотрудничество». Заявки уходят в Telegram и дублируются на e-mail через PHP-обработчик `public/api/lead.php`.

Сайт — обычные файлы HTML, CSS и JS без сборки. Всё, что нужно загрузить на хостинг, лежит в папке `public/`.

## Структура

```
public/                 ← содержимое этой папки загружается в public_html
  index.html            главная страница
  privacy.html          политика обработки персональных данных
  consent.html          согласие на обработку персональных данных
  404.html              страница «не найдено»
  robots.txt            sitemap.xml появляется после команды set-site-url (см. ниже)
  .htaccess             настройки Apache (404, закрытые папки, кеш)
  favicon.svg
  assets/css/main.css   все стили (цвета и шрифты — в начале файла, в :root)
  assets/js/main.js     меню, анимации, лента
  assets/js/lead-form.js форма заявки
  assets/fonts/         шрифты Unbounded, Manrope, JetBrains Mono (лицензия OFL — OFL.txt)
  assets/img/           3D-изображения рулонов
  api/lead.php          приём заявок
  app/                  код обработчика и настройки (закрыт от браузера)
  storage/              служебные файлы (закрыт от браузера)
tests/                  проверки (не загружаются на хостинг)
tools/                  рендер изображений, проверка секретов, адрес сайта, роутер для npm run dev (не загружаются)
site.config.json        адрес сайта (siteUrl); меняется командой npm run set-site-url
```

## Запуск на своём компьютере

Нужны PHP 7.4+ и Node.js 18+ (Node — только для тестов и рендера картинок).

```bash
npm install          # инструменты для проверок
npm run dev          # сайт на http://127.0.0.1:8080 (app/ и storage/ отвечают 403, как на хостинге)
npm test             # проверка PHP, отсутствия секретов, обработчика заявок и браузерные тесты
```

Без настроек форма честно отвечает «Форма пока не подключена — заявка не отправлена…», а введённые данные остаются на странице.

Если в браузере выключен JavaScript, форма уходит обычной отправкой, и обработчик отвечает понятной страницей (заявка принята, ошибки полей, форма не подключена…) со ссылкой «Вернуться к форме». Скрипт формы получает тот же итог в JSON.

## Размещение на Timeweb или Beget

1. **Хостинг с PHP 7.4 или новее** — подходит любой тариф виртуального хостинга. В панели проверьте версию PHP для сайта (лучше 8.x).
2. **Загрузите содержимое `public/`** (не саму папку, а то, что внутри, включая скрытые `.htaccess`) в корневую папку сайта: на Timeweb обычно `public_html`, на Beget — `ИМЯ_САЙТА/public_html`. Через файловый менеджер панели или по FTP/SFTP. Папки `tests/`, `tools/`, `node_modules/` загружать не нужно.
3. **Создайте файл настроек `app/config.php`** на хостинге: скопируйте `app/config.example.php` в `app/config.php` (в файловом менеджере — «Копировать», затем переименовать) и впишите значения (см. ниже). Этот файл не хранится в репозитории и закрыт от браузера.
   Вместо файла можно задать переменные окружения с теми же именами — они важнее файла.
4. **Включите HTTPS** — в панели хостинга выпустите бесплатный сертификат Let's Encrypt для домена.
5. **Пропишите адрес сайта — до загрузки файлов** (на своём компьютере, в папке проекта):
   ```bash
   npm run set-site-url -- https://vsecheki.ru
   ```
   Подставьте свой домен: только `https://` и домен, без пути (кириллический тоже можно: `https://всечеки.рф`). Команда записывает адрес в `site.config.json` и проставляет его в `index.html` (canonical, Open Graph `og:url` и `og:image`, JSON-LD), `privacy.html`, `consent.html` (canonical), `robots.txt` (строка `Sitemap:`) и создаёт `sitemap.xml`. Сменили домен — запустите ещё раз с новым адресом, старый заменится везде. `npm run set-site-url -- ""` возвращает исходное состояние.
   Пока адрес не задан, на сайте нет canonical, `og:url` и `sitemap.xml`, а картинка для ссылок указана путём `/assets/img/og-image.png`. Сайт работает, но превью в мессенджерах и поисковики ждут полного адреса — поэтому этот шаг нужен до публикации.
6. **Проверьте форму:** отправьте тестовую заявку с сайта — она должна прийти в Telegram и на почту.

Папка `storage/` создаётся и заполняется сама (лимит частоты заявок, резервная копия). Если хостинг запрещает запись в `public_html`, выдайте папке `storage/` права на запись (обычно 755).

**Надёжнее держать хранилище вне `public_html`.** `storage/` внутри сайта закрыта `.htaccess`, но если хостинг его не читает (например, Nginx без Apache), резервные заявки станут доступны из браузера. Создайте папку рядом с `public_html` (не внутри) и впишите её полный путь в `app/config.php` ключом `'STORAGE_DIR' => '/полный/путь/к/storage'` (или в переменную окружения `STORAGE_DIR`). Полный путь к сайту показывает файловый менеджер панели хостинга.

## Настройки приёма заявок

Заполняются в `app/config.php` (или в переменных окружения). Достаточно одного канала: если настроен только Telegram или только почта, заявки уходят туда.

| Ключ | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `TELEGRAM_CHAT_ID` | ID чата, куда бот пишет заявки |
| `LEAD_EMAIL_TO` | адрес, куда дублировать заявки (можно несколько через запятую) |
| `LEAD_EMAIL_FROM` | адрес отправителя писем (лучше ящик на том же домене или тот же, что в SMTP) |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_SECURE` | SMTP-сервер; если `SMTP_HOST` пуст, письмо отправляется через `mail()` хостинга |

### Как получить токен бота и ID чата

1. В Telegram откройте **@BotFather**, отправьте `/newbot`, придумайте имя и логин бота. BotFather пришлёт **токен** — впишите его в `TELEGRAM_BOT_TOKEN`.
2. Откройте своего бота и нажмите **Start** (или добавьте бота в группу, куда должны приходить заявки, и напишите в группе любое сообщение).
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (подставьте свой токен). В ответе найдите `"chat":{"id": …}` — это **ID чата**. Для группы он начинается с минуса — копируйте вместе с минусом в `TELEGRAM_CHAT_ID`.

### Как отправлять почту через SMTP Яндекса

Письма через `mail()` хостинга часто попадают в спам или не доходят до Яндекса, поэтому надёжнее SMTP:

1. В Яндекс ID → «Безопасность» → **«Пароли приложений»** создайте пароль для приложения «Почта».
2. В настройках Яндекс Почты → «Почтовые программы» включите доступ **по протоколу IMAP / «С сервера imap.yandex.ru»** (без этого SMTP может не принять вход).
3. Заполните:
   - `SMTP_HOST` — `smtp.yandex.ru`
   - `SMTP_PORT` — `465`
   - `SMTP_SECURE` — `ssl`
   - `SMTP_USER` — ваш адрес на Яндексе
   - `SMTP_PASSWORD` — пароль приложения из шага 1 (не основной пароль)
   - `LEAD_EMAIL_FROM` — тот же адрес, что в `SMTP_USER`
   - `LEAD_EMAIL_TO` — куда присылать заявки

### Если заявка не дошла

Если не сработал ни один канал, посетитель видит «Не удалось доставить заявку…», а заявка сохраняется в `storage/failed-leads.jsonl` на сервере (файл закрыт от браузера). Загляните туда через файловый менеджер, если в логах хостинга есть ошибки доставки. Файл растёт только при сбоях — после разбора его можно удалить.

Защита от спама: скрытое поле-ловушка, минимум 3 секунды на заполнение формы, не больше 5 заявок с одного IP за 10 минут. Попытки, когда форма ещё не подключена, в этот лимит не входят.

## Как заменить изображения

Картинки — 3D-визуализации, сделанные скриптом `npm run images` (`tools/render/`). Для перерендера, кроме `npm install` и Chromium для Playwright (`npx playwright install chromium`), нужны **python3** с пакетами **Pillow** (WebP и PNG) и **fontTools** (контуры логотипа и favicon): `python3 -m pip install Pillow fonttools`. Чтобы поставить свои фотографии, замените файлы в `public/assets/img/` **с теми же именами и пропорциями**:

| Файл | Где на сайте | Размер |
|---|---|---|
| `hero-roll.webp` и `hero-roll.png` | первый экран, рулон с лентой (прозрачный фон) | 1600 × 1600 |
| `roll-57x40.webp` и `.png` | карточка формата 57 × 40 | 1000 × 1000 |
| `roll-80x80.webp` и `.png` | карточка формата 80 × 80 | 1000 × 1000 |
| `production-roll.webp` и `.png` | раздел «Производство»: непрозрачный фон, края сходят в цвет секции `#141517` | 1600 × 1200 |
| `og-image.png` | картинка для ссылок в соцсетях и мессенджерах | 1200 × 630 |
| `apple-touch-icon.png` | иконка на экране телефона | 180 × 180 |

Если ставите настоящие фотографии, поправьте в `index.html` атрибуты `alt` (там написано «3D-визуализация») и строку в подвале «Изображения продукции на сайте — 3D-визуализации».

## Куда вставить счётчик (Яндекс Метрика и т. п.)

Аналитики на сайте нет. Код счётчика вставьте в `index.html` перед закрывающим `</head>` (и при желании в `privacy.html`, `consent.html`). После этого допишите в `privacy.html`, раздел 2, что сайт использует счётчик посещаемости и cookie, — сейчас там сказано, что их нет.

## Тексты и факты

На сайте только факты, которые сообщил владелец: название, кассовая лента, собственное производство (место производства на сайте не называется; Липецк в контактах и реквизитах — это город ИП), качественные немецкие материалы, работа напрямую, выгодные цены (без цифр), опт, долгосрочное сотрудничество, отправка в любой регион России, форматы 57 × 40 и 80 × 80 (подпись «ширина × намотка, мм»), другие размеры — под заказ (распространённые размеры приведены со словом «например»), контакты, реквизиты ИП. Цены, характеристики, сертификаты, сроки доставки и отзывы не указаны намеренно — добавляйте их, только если они точные.

Тексты правятся прямо в HTML-файлах. Для красивых переносов между коротким словом и следующим стоит `&nbsp;` — сохраняйте его при правке.

## Что ещё сделать владельцу

- Купить домен и выполнить `npm run set-site-url -- https://ваш-домен` (см. выше).
- Подтвердить коммерческие формулировки на сайте, которые не взяты дословно из ваших слов: «другие размеры — под заказ» как обещание, примеры размеров, назначение ленты (кассовые аппараты, онлайн-кассы, POS- и чековые принтеры), список партнёров, шаги работы.
- Заполнить `app/config.php` на хостинге.
- Как оператор персональных данных — подать уведомление в Роскомнадзор (pd.rkn.gov.ru) и проверить тексты `privacy.html` и `consent.html` с юристом: в них нет адреса оператора, только город.
- В уведомлении Роскомнадзору **отметить трансграничную передачу**: заявки доставляются через Telegram (Telegram Messenger Inc., иностранная компания). Перед началом такой передачи закон требует отдельно уведомить Роскомнадзор о ней. Политика и согласие на сайте эту передачу уже называют; если откажетесь от Telegram и оставите только почту, уберите эти строки из `privacy.html` (раздел 5) и `consent.html` (раздел 3).
