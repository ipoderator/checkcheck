## Что должно заработать

Новая предметная визуализация кассовой ленты для тёмного раздела «Производство» заменяет стопку рулонов. Её края растворяются в фон `#141517`. PNG-запасные стали лёгкими. Проверка «нет секретов» ловит все формы записи, найденные аудитом.

## Критерии приёмки

- [ ] `npm run images` создаёт `production-roll.webp` и `.png` 1600 × 1200. Это кассовая лента в студийном свете на тёмном фоне, близком к `#141517`. Края кадра сходят ровно в `#141517`, без видимой рамки, фон непрозрачный. WebP ≤ 250 КБ
- [ ] Композиция заметно сильнее старой стопки: например, 2–3 рулона разных форматов и лента, уходящая из кадра, с контровым светом. Без цеха и станков: нельзя изображать вымышленное производство. На ленте нет цифр-фактов
- [ ] `rolls-stack.*` удалены из `public/assets/img`, из рендера (`render.mjs`, `shots.js`) и из `images.test.mjs`
- [ ] Каждый PNG в `public/assets/img` ≤ 400 КБ (квантование палитры), без видимых полос на градиентах тени. Сравни глазами до и после
- [ ] `check-secrets` ловит: числа без кавычек, `SetEnv` в `.htaccess`, `define()`, `$c['KEY'] =`, запасные значения после `getenv(...) ?:` и `||`, голые токены Telegram. На каждую форму — тест, сначала красный; ложных срабатываний на текущем репозитории нет
- [ ] Картинку посмотреть глазами на фоне `#141517`; `npm test` зелёный в части своей зоны
