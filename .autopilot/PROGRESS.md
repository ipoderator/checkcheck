## Известные баги

- SMTP через ssl/STARTTLS и PHP 7.4 не проверены вживую; STARTTLS в тестах — только до рукопожатия, режим ssl не покрыт; два SMTP-теста требуют IPv6 (`::1`)
- Проверка «нет секретов» в `.autopilot/` ищет только токен Telegram; формы `.ini`/`.env`/YAML/heredoc не ловятся
- Без JS кнопки «Оставить заявку на сотрудничество» / «Стать партнёром» ведут к форме с выбранным «Рассчитать цену» — «Сотрудничество» отмечается вручную
- Без JS «Вернуться к форме» со страницы ответа теряет введённое; на странице «Форма пока не подключена» нет совета нажать «Назад»
- У вкладки «Сотрудничество» нет полей формата и объёма — блок советует писать их в комментарии
- Если включить «уменьшить движение», пока лента едет, кончик ленты может сместиться до перезагрузки (`main.js`, обработчик не отменяет кадр)
- Синхронизация темы между вкладками (`storage`) и несколькими кнопками не покрыта тестами
- Печать без фонов: тёмные секции главной и подвал — светлый текст на белом
- `docs/architecture.md` описывает `theme-color` как один тег, а их два с `media`
- `tools/set-site-url.mjs` принимает адрес с портом (`https://a.ru:8443`)
- README: для e2e на чистой машине нужен `npx playwright install chromium` — сказано только для рендера картинок
