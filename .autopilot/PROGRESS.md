# Сайт «ВсеЧеки» — что осталось

Последняя сборка: `.autopilot/2026-10-17-thermo-tape-site/` — сайт производителя кассовой ленты; третья задача: без раздела «Производство», новое «Сотрудничество», светлая и тёмная тема, заметная лента, два рулона на первом экране; проверен локально, не опубликован.

## Договорились — не пересматривать

- Факты на сайте — только сообщённые владельцем: «Не придумывай цены, характеристики, сертификаты, клиентов, отзывы, контакты и другие факты, которых я не сообщил» (R21–R27)
- «полностью убери упоминания немецкого города Лейпциг»; «Новое место производства не придумывай» (R08 снят, G15–G17, G44) — тест `tests/api/no-leipzig.test.mjs`
- «Липецк в контактах и юридических реквизитах — другой город. Не удаляй и не меняй его.» (G18, G45)
- Форматы 57 × 40 и 80 × 80, без слова «основные»; «57 на 40 это намотка» — подпись «ширина × намотка, мм»; другие размеры — под заказ, примеры с «например» (G01, G02, G23, G24)
- «Фото нет - сделай их сам» — 3D-визуализации, не выдаются за фото (G03, G20); на первом экране — два рулона 57 × 40 и 80 × 80 без подписи: «2. Да» (G46, G47)
- «убери отдельную большую секцию производства» — её факты строкой в «Почему ВсеЧеки» (G37, G38, ADR 0012)
- Лента: при прокрутке вниз выезжает, вверх — сматывается; шире и видна на телефоне: «1. Да» (G35, G36)
- Тема: переключатель в шапке, выбор запоминается; без выбора — тема системы (G42, G43, ADR 0010)
- Коммерческие формулировки оставить как есть до правки владельцем: «ДАвай» (брифинг 2026-10-18)
- Заявки — в Telegram с дублем на e-mail; токен, chat id, адрес почты — пустые, вне кода (G06–G09)
- «Публиковать сайт без моего отдельного разрешения не нужно»; «Сайт не публикуй» (G12, G30, G55)
- Страна — Россия; «Сотрудничество - это все» (R37i, R20)

## Не доделано

- Публикация, домен, хостинг — ждут разрешения владельца; адрес задаётся `npm run set-site-url -- https://…` (G12, G22)
- Полный адрес оператора ПДн в `privacy.html` и `consent.html` — дан только «г. Липецк» (R35i)
- Коммерческие формулировки ждут подтверждения владельца: назначение ленты (кассы, онлайн-кассы, POS- и чековые принтеры), «магазины, сети, дилеры, сервисные компании», «единственное, что мы делаем», ярлык «Германия», шаги «рассчитаем и свяжемся», «условия доставки обсудим при расчёте», «без посредников», примеры размеров (R27, G31)

## Известные баги

- SMTP через ssl/STARTTLS и PHP 7.4 не проверены вживую; STARTTLS в тестах — только до рукопожатия, режим ssl не покрыт; два SMTP-теста требуют IPv6 (`::1`)
- Проверка «нет секретов» в `.autopilot/` ищет только токен Telegram; формы `.ini`/`.env`/YAML/heredoc не ловятся
- Без JS кнопки «Оставить заявку на сотрудничество» / «Стать партнёром» ведут к форме с выбранным «Рассчитать цену» — «Сотрудничество» отмечается вручную
- Без JS «Вернуться к форме» со страницы ответа теряет введённое; на странице «Форма пока не подключена» нет совета нажать «Назад»
- У вкладки «Сотрудничество» нет полей формата и объёма — блок советует писать их в комментарии
- Если включить «уменьшить движение», пока лента едет, кончик ленты может сместиться до перезагрузки (`main.js`, обработчик не отменяет кадр)
- Синхронизация темы между вкладками (`storage`) и несколькими кнопками не покрыта тестами
- Печать без фонов: тёмные секции главной и подвал — светлый текст на белом
- `docs/architecture.md` описывает `theme-color` как один тег, а их два с `media`
- `tools/set-site-url.mjs` принимает адрес с портом (`https://a.ru:8443`)
- README: для e2e на чистой машине нужен `npx playwright install chromium` — сказано только для рендера картинок
