# Перенесено из прошлой сборки

## Из PROGRESS.md

Последняя сборка: `.autopilot/2026-10-17-thermo-tape-site/` — сайт производителя кассовой ленты с формой заявок (Telegram + e-mail), проверен локально, не опубликован.

## Договорились — не пересматривать

- Факты на сайте — только сообщённые владельцем: «Не придумывай цены, характеристики, сертификаты, клиентов, отзывы, контакты и другие факты, которых я не сообщил» (R21–R27)
- Форматы: «Размеры 57 на 40 и 80 на 80», плюс любые размеры под заказ с общедоступными примерами (G01, G02)
- «Фото нет - сделай их сам» — на сайте 3D-визуализации, не выдаются за фото (G03)
- Заявки — в Telegram с дублем на e-mail; токен, chat id, адрес почты — пустые, вне кода (G06–G09)
- «Публиковать сайт без моего отдельного разрешения не нужно» (G12)
- Страна — Россия; «Сотрудничество - это все» (R37i, R20)

## Не доделано

- Публикация, домен, хостинг — ждут отдельного разрешения владельца; заглушка `https://ДОМЕН` в sitemap/robots/og (G12, R38i)
- Полный адрес оператора ПДн в `privacy.html` и `consent.html` — дан только «г. Липецк» (R35i)
- Формулировки-выводы из брифа ждут подтверждения владельца: подпись «ширина × намотка», назначение ленты (кассы, POS-принтеры), список «магазины, сети, дилеры, сервисные компании», шаги «свяжемся с вами», «без посредников» (R27, слепая приёмка)

## Известные баги

- SMTP через ssl/STARTTLS и работа на PHP 7.4 не проверены вживую — только тестами на заглушках и линтером
- `tools/check-secrets.mjs` не ловит `define()`, `$_ENV[…]=…`, числа в JSON
- PNG-запасные изображения тяжёлые (~1 МБ) — `public/assets/img/*.png`
- Два SMTP-теста в `tests/api/channels.test.mjs` требуют IPv6 (`::1`)
