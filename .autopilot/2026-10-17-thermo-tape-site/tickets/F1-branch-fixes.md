## Что должно заработать

Правки по итогам общего ревью: согласие не восстанавливается из черновика; политика ПДн правдиво описывает код и называет передачу в Telegram; длинная заявка не ломает Telegram; локальный сервер не отдаёт служебные файлы; бегущую строку можно остановить; README называет зависимости для перерендера.
