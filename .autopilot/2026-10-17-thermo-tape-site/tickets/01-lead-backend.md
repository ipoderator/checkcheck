## Что должно заработать

Отправленная на `POST /api/lead.php` заявка уходит в Telegram и дублируется письмом. Настройки берутся из переменных окружения или из `app/config.php`, в репозитории они пустые. Пустой конфиг даёт `not_configured`, частичный сбой даёт успех, полный сбой — `delivery_failed`, а заявка при этом пишется в резервный файл. Бот-ловушка, слишком быстрая отправка и лимит частоты работают. Есть каркас проекта: `npm run dev` поднимает сайт, `npm test` гоняет все проверки. Все dev-зависимости проекта установлены сразу: Playwright и Three.js (последний — для таска рендера).

## Из брифа, дословно

> «Подготовь его для размещения на обычном хостинге с поддержкой PHP, например Timeweb или Beget. Заявки должны отправляться в Telegram и дублироваться на e-mail.»
> «Токен Telegram-бота, ID чата и адрес почты оставь пустыми в отдельном конфигурационном файле или переменных окружения. Никаких секретных данных в коде быть не должно. Если настройки не заполнены, форма должна показывать понятное сообщение и сохранять введённые пользователем данные на странице. Публиковать сайт без моего отдельного разрешения не нужно.»
> «Главная цель — получение заявок на расчёт цены и сотрудничество.»

## Критерии приёмки

- [ ] `package.json` содержит скрипты `dev`, `test`, `images` (`node tools/render/render.mjs` — сам скрипт пишет таск 02) и все devDependencies: `playwright`, `@playwright/test`, `three`; `playwright.config.mjs` запускает `php -S` для e2e (`tests/e2e`, создаёт таск 03)
- [ ] `npm run dev` поднимает `php -S 127.0.0.1:8080 -t public`; `npm test` — одна команда, зелёная
- [ ] Контракт ответов выполнен целиком (200/400/405/422/429/502/503), в порядке проверок из `interfaces.md`; тесты `tests/api` на каждый код, на валидацию каждого поля (телефон: `8 (920) 243-19-57` → `+79202431957`; 9 цифр → ошибка), на `format=other` без `format_custom`
- [ ] Ловушка и отправка быстрее 3 с: ответ `{"ok":true}`, ни в один канал ничего не ушло
- [ ] Шестая заявка с одного IP за 600 с даёт 429; файлы лимита старше часа чистятся
- [ ] Telegram: одно сообщение `sendMessage` с типом, всеми заполненными полями, временем по Москве и страницей; HTML-экранирование данных; проверено на поддельном сервере через `TELEGRAM_API_BASE`
- [ ] E-mail: UTF-8 (тема в `=?UTF-8?B?…?=`), `Reply-To` клиента, если указан; транспорты `mail`, `smtp` (свой клиент на сокетах: EHLO, STARTTLS/SSL, AUTH LOGIN), `file` — для тестов
- [ ] Настроен только один канал → 200; оба настроены, один падает → 200; оба падают → 502 и строка в `storage/failed-leads.jsonl`
- [ ] Конфиг: env важнее `app/config.php`; `config.example.php` с пустыми значениями; `app/config.php` и `.env` в `.gitignore`; `.env.example` перечисляет имена
- [ ] `public/app/` и `public/storage/` недоступны через Apache (`.htaccess` `Require all denied`); прямой запрос к `app/*.php` ничего не исполняет (guard-константа из `api/lead.php`)
- [ ] `tools/check-secrets.mjs` в `npm test`: падает, если у любого из ключей конфига в отслеживаемых файлах есть непустое значение
- [ ] Весь PHP проходит `php -l` и не использует конструкции новее 7.4 (список в `interfaces.md`)
