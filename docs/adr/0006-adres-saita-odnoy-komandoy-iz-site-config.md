# 0006. Адрес сайта задаётся одной командой из `site.config.json`, без заглушки домена

## Контекст

Домена пока нет, а canonical, Open Graph, JSON-LD, `sitemap.xml` и `robots.txt` требуют абсолютных адресов. В первой сборке там стояла заметная заглушка `https://ДОМЕН`; аудит (G22) отметил, что она попадает в Open Graph и может уйти на боевой сайт, если про неё забыть. Сайт статический (0001), PHP для страниц не используется.

## Решение

Адрес хранится в одном месте: `site.config.json` с полем `siteUrl` (по умолчанию пустая строка). Команда `npm run set-site-url -- https://пример.рф` (`tools/set-site-url.mjs`) проверяет адрес (только https, без пути), записывает его в `site.config.json`, проставляет абсолютные canonical, `og:url`, `og:image` и `url`/`logo`/`image` в JSON-LD, генерирует `sitemap.xml` и строку `Sitemap:` в `robots.txt`. Повторный запуск с другим адресом меняет его везде.

Пока `siteUrl` пуст, canonical, `og:url` и `sitemap.xml` отсутствуют, а остальные ссылки (в том числе `og:image`) — корневые пути. Слова `ДОМЕН` на сайте нет.

## Почему

- Заглушка `https://ДОМЕН` с ручной заменой отвергнута: поиск и замена по нескольким файлам легко пропускают место, а недозаменённая заглушка молча уходит в публикацию. Пустое значение безопаснее видимой выдумки.
- Определение адреса на лету по заголовку `Host` отвергнуто: страницы и `sitemap.xml` отдаёт хостинг как статику без PHP (0001), а заголовок `Host` приходит от клиента и годится для canonical хуже, чем явно заданное значение.
- Только относительные ссылки отвергнуты: `og:image`, `sitemap.xml` и JSON-LD по формату требуют абсолютных адресов, а canonical с чужим адресом хуже, чем его отсутствие.
- Команда вместо правки руками выбрана ради единственной точки: адрес меняется в одном месте, а проверка формата ловит ошибки до публикации.

## Последствия

- Для публикации нужен Node (или разработчик с ним): на хостинге команда не запускается. Владелец без Node подставляет адрес через разработчика; шаг описан в README.
- Скрипт переписывает уже готовые HTML-файлы, поэтому разметка мест подстановки должна оставаться разбираемой; правка этих мест руками обойдёт скрипт и разведёт адреса.
- Результат команды (`sitemap.xml`, `robots.txt`, HTML) коммитится; смена адреса — отдельный коммит.
- До указания адреса предпросмотр в соцсетях не работает (`og:image` без домена), а поисковики не получают canonical и карту сайта. Это допустимо, пока сайт не опубликован (G12, G30).
- Тест обязан следить, что слова `ДОМЕН` нигде нет, а при непустом `siteUrl` ни один адрес не остался корневым там, где нужен абсолютный.
